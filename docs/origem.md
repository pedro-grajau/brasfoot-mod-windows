# Origem do projeto

Este projeto deriva de [pedro-grajau/brasfoot-linux](https://github.com/pedro-grajau/brasfoot-linux), commit `7e16a0bbfa9bf07883af789a4092fbb3512e7efa`.

O projeto de origem implementou a extração do aplicativo Java do instalador, Mundial de 32 clubes, Intercontinental, troféus, integração com a carreira, premiações e rankings. Os nomes e avisos de licença dos arquivos originais foram preservados.

Esta versão acrescenta preparação e atalhos para Windows, caminhos e classpaths compatíveis, a taça Sul-Minas, o painel unificado de Tabelas e correções na seleção de competição/fases. A estrutura foi reorganizada para que o código fique na raiz do repositório e os arquivos locais do jogo sejam ignorados pelo Git.

O motor original do Brasfoot não foi reescrito e não faz parte da distribuição deste repositório. Licença do código: [GPL-3.0-only](../LICENSE). Materiais de terceiros: [NOTICE.md](../NOTICE.md).
